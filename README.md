-- Retail Sales Analysis --

A beginner-friendly data analysis project using Python, Pandas, SQLite, SQL, and Matplotlib to analyze retail sales data and extract useful business insights.

The project loads a retail sales dataset into a SQLite database and uses SQL queries to analyze revenue, product categories, customer spending, age groups, gender, monthly sales trends, and month-over-month revenue changes. The results are then visualized using Python and Matplotlib.

The main goal of this project was to practice combining SQL with Python for data analysis and visualization.
